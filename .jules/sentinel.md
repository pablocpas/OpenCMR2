## 2026-11-19 - Stack buffer overflow in command-line parsing (Args_Parse)
**Vulnerability:** Stack buffer overflow in `Args_Parse` (game/Graphics.cpp). The `word[260]` stack buffer had no bound check when copying command-line tokens, so any token longer than 259 bytes wrote past the buffer. Additionally, the 20-entry argument array `g_unk0x00816820` had no count check, so the 21st+ argument wrote past the array.
**Learning:** The decompiled original code preserved the original's unbounded `word[260]` copy and fixed-size 20-entry array without any bounds checking, assuming command-line input was trusted. Command-line arguments are user-controlled and reachable at process startup before any other validation.
**Prevention:** Bound every fixed-buffer copy to the buffer size, and cap fixed-array writes to the array length. Return early when the limit is reached rather than writing out of bounds. Add a regression test (tests/args_parse_test.cpp) that reproduces both overflows and confirms bounds are enforced; verify under AddressSanitizer.
